- Confirm final experiment settings, stage schedules, model/judge identities and target hardware. Shared configuration files contain recovered engineering choices.
- Supply approved datasets, local model weights and judge service access. Historical dialogue construction and final selection are not reconstructed; text-only preparation interfaces do not establish dataset quality.
- Verify service scoring, numerical behavior of neural retrieval, CUDA/distributed execution and end-to-end results in the target runtime. Source inspection does not establish experiment reproduction.
- Author-owned code now uses MIT; confirm source/data redistribution rights for any proposed research artifacts. Third-party licenses and attribution remain separate.
- Review Git history independently before public release. Local source export excludes history and research evidence; it does not publish the source.

The repository provides core generation, rewards, prepared-data interfaces, evaluation and GRPO integration. Paper plotting/statistical analysis assets and private clinical records are outside the release scope.
